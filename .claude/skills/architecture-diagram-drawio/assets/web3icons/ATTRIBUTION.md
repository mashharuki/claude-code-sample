# Attribution

The SVG icons under this directory are a curated subset (47 of 2000+) of the
`raw-svgs/*/branded` icons from:

**web3icons** — https://github.com/0xa3k5/web3icons
Copyright (c) 2024 0xa3k5
License: MIT (see below)

Vendored categories: `networks/` (chain logos), `tokens/` (token logos),
`wallets/` (wallet app logos), `exchanges/` (DEX/CEX protocol logos).

To add more icons beyond this curated set, fetch the SVG from
`https://github.com/0xa3k5/web3icons/tree/main/raw-svgs/<category>/branded`
into the matching folder here — `scripts/web3icons.py` picks it up
automatically by filename, no code change needed.
